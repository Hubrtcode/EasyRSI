
# Easy RSI Indicator

A simplified and more readable version of the Relative Strength Index (RSI), designed to improve clarity and provide better context when analysing market momentum.

## Overview

This indicator enhances the traditional RSI by reducing visual noise and incorporating price context directly into the analysis. It is built for traders who want a clearer view of overbought and oversold conditions without overcomplicating their charts.


## Features

- Simplified RSI for improved readability  
- Visual alignment between price and momentum  
- Clear identification of overbought and oversold zones  
- Lightweight and easy to use on any chart  

## How It Works

The indicator is based on the standard RSI calculation but presents the data in a more intuitive format. By displaying price behaviour alongside RSI, it helps users better understand how momentum relates to actual market movement.
 
## Use 

- Identifying overbought and oversold conditions  
- Confirming momentum during trends  
- Improving chart clarity by replacing standard RSI  

## Notes

- This indicator does not provide financial advice  
- It should be used alongside other analysis methods  
- Market conditions can change, and no indicator is always accurate
- Capital at risk
